Your academic data stays local by default.

Smart UMN is an independent student planning tool, not affiliated with or endorsed by the University of Minnesota. Official APAS, advising, registration and University policies remain authoritative.

What the extension reads

After you sign in on official UMN pages, the extension reads the rendered APAS audit needed for planning and stores a normalized academic profile in this browser. Chrome policy treats page content as potentially sensitive user data, so Smart UMN discloses this as website content. Raw authenticated APAS HTML, passwords, cookies, Duo codes, SAML assertions and authorization headers are not uploaded to Smart UMN.

What is sent to the public-evidence API

Smart UMN sends public course code, term and Twin Cities campus code when requesting current offerings and course evidence. Review-only policy lookup may also send a bounded requirement phrase (maximum 2,000 characters) plus program/catalog metadata. The API does not accept raw APAS HTML, completed-course history, saved schedules, credentials or student identifiers. Smart UMN application code does not log or persist policy-query text, request bodies, IP addresses or student profiles.

Netlify hosts the public Web/API and necessarily processes normal connection metadata under its own terms. Smart UMN uses no advertising or analytics scripts.

How local data is used

The normalized profile, preferences and saved plans support APAS-aware planning and Schedule Builder Course Intelligence. Smart UMN does not sell academic data, use it for advertising, build advertising profiles, or transfer it to data brokers. Humans do not read individual profiles through a Smart UMN backend because those profiles are not stored there.

Permissions

storage keeps normalized APAS/planning state locally. alarms schedules periodic APAS refresh after a connection exists. Access to UMN uAchieve reads the audit, Schedule Builder renders Course Intelligence, and smartumn.qinyangtan.com bridges the local profile to this Web and serves public evidence. The extension does not request cookie, history, geolocation, clipboard, downloads, all-sites, webRequest or Side Panel permissions and does not execute remotely hosted JavaScript.

External evidence

RateMyProfessors and Reddit links open the original sites. Historical grades come from the public GopherGrades service; a professor rating aggregate appears only when GopherGrades already republishes it, with a link to its source. Smart UMN does not scrape RateMyProfessors or Reddit. Historical grades, professor ratings and community discussion are optional context, not predictions or degree authority. Policy retrieval is review-only and has no authority to decide whether a requirement is satisfied.

Delete your data

Use “Forget local academic data,” clear site data for smartumn.qinyangtan.com, and remove the extension if desired. Removing the extension clears its extension storage but does not automatically clear this Web origin's local storage. Browser storage is not application-level encrypted; someone with access to your device or Chrome profile may be able to read it.

Support and security

For help or privacy questions, use the Smart UMN support page. Do not send private audits, student IDs, passwords or authentication material in public support messages.
